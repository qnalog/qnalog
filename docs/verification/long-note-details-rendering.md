## 数值采样状态

曾尝试从嵌入开发者工具查询 DOM 与 `scrollHeight`。查询上下文在切换笔记后没有稳定绑定编辑器，返回的 `details`、注释行、标题行数量和高度均为零或固定视口值。该批数据无效，未用于上表。一次 V0 的局部查询在滚动前返回 `scrollHeight=74,475`、`scrollTop=0`，滚动后返回 `scrollHeight=392,895`、`scrollTop=955`；查询目标仍未能确认是完整编辑器文档，因此只记录为诊断线索，不作为测量结论。

当前可用的桌面自动化接口提供原生滚轮输入和辅助功能树，没有提供 CDP 会话或页面脚本执行接口。本轮未完成任务要求的每 0.5 秒轮询、真实鼠标滚轮分步采样、长短笔记全部变体的 0/50/100% 数据收集。未据此修改转写写入格式，也未判定为 Obsidian 固有行为。

## 测试数据

临时笔记由 `buildConsolidatedNoteContent`、`attachTextTranscript` 与 `serializeTranscriptBlock` 生成。长变体的数据目标行长为 1,700、5,400、11,200、20,500、21,500、13,300 字符；短变体取前三段。为对比行长而填充的 JSON 增加了合成 `filler` 字段，插件会拒绝把它当作正式转写元数据，因此这些文件只适用于渲染观察，不适用于读取兼容性测试。

后续完成测量时，应先用有效的序列化转写结构生成长度匹配的合成文本，再通过 CDP 的 `Input.dispatchMouseEvent` 滚动并在编辑器所在 WebView 中采样 DOM。记录实际视口坐标、编辑器滚动容器、文档高度和每次采样时间，避免跨笔记查询错误上下文。
